# Termates brand

- **Name:** Termates (terminal + teammates). One agent terminal is a **cligent**.
- **Logo:** a circle holding a terminal window whose cursor is a right-pointing
  triangle. Neon green `#5ef08a` (core `#b6ffcb`) on `#081818` with a faint grid.
- `logo.svg` — source for `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`.
- `logo-small.svg` — simplified source for `favicon-32.png` / `favicon.png` and `favicon-16.png`.
- The in-app glyph is the `logo` entry in `client/src/components/atoms/Icon.tsx`
  (stroked in `currentColor`, so it follows the theme accent).
